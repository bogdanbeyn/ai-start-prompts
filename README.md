# Рисуй командой

Интерактивная шпаргалка AI-Старт: 50 визуальных команд для ChatGPT. Страница на HTML, CSS и JavaScript, без сторонних библиотек.

Можно копировать короткую команду, собрать полный промпт в конструкторе, соединить до трёх режимов, пройти проверку на восьми ситуациях и скачать весь набор одним файлом.

## Запуск

Из корня проекта:

```bash
python3 -m http.server 47231
```

Откройте `http://127.0.0.1:47231`.

## Заявки

Форма скачивает текстовый файл и запоминает имя с контактом в браузере. Чтобы заявки уходили вам, укажите адрес приёма в `js/app.js`:

```js
var CONFIG = {
  leadEndpoint: "https://example.com/lead",
  telegram: "https://t.me/AI_Start_Course",
  instagram: "https://instagram.com/AI_Start_Course",
  tiktok: "https://www.tiktok.com/@AI_Start_Course"
};
```

На `leadEndpoint` уходит `POST` с JSON: `name`, `contact`, `source`. Ссылки соцсетей на странице берутся из этого же объекта.

Команды вроде `/handwritten` — условные названия визуальных режимов, а не встроенные функции ChatGPT. К команде лучше добавлять описание оформления: конструктор собирает его сам.

В исходном списке не было примера у пяти режимов. На странице стоят такие темы, их можно заменить в `js/data.js`:

- `/infographic` — Как устроено внимание на уроке
- `/watercolor` — Весенний сад после дождя
- `/cinematic` — Ночной поезд на пустой станции
- `/slide` — 5 правил сильного урока
- `/carousel` — 7 ошибок в первых сообщениях клиенту
